# Sistema de ventas (Parte 3) — código tal cual la guía

    python main.py

Ejecutar desde esta carpeta (los JSON se guardan en `data/`). Python 3.8+, sin librerías externas.

Archivos: `models.py` (Cliente, Producto, Venta, DetalleVenta), `views.py` (CrudBase + controladores),
`main.py` (menús), `shared/` (GestorJSON y funciones de consola; la guía no los incluye, se reconstruyeron).
